# 001. R と Python の考え方の違い — まず押さえる5点

!!! abstract "この項目の R→Python 対応"
    - **R**: すべてがベクトル、添字は **1 始まり**、代入は `<-`、欠損は `NA`
    - **Python（推奨）**: 数値配列は **NumPy / pandas**、添字は **0 始まり**、代入は `=`、欠損は `NaN` / `None`
    - **要注意**: 素の Python の `list` は R の `c()` と**似て非なるもの**（`* 2` で繰り返しになる）

R から Python に移ると、文法以前に「発想」が5か所ずれます。ここを最初に押さえると、以降の項目がすべて楽になります。

---

## 1. ベクトル化：R は最初から、Python は NumPy で

R は数値の集まり（ベクトル）に対する一括演算が言語の中心です。Python でこれを得るには **NumPy 配列**（や pandas の `Series`）を使います。

```r
x <- c(10, 20, 30, 40)
x * 2          # 各要素が2倍に
x[1]           # 1番目の要素（1始まり）
mean(x)
is.na(NA)
```

出力:

```text
[1] 20 40 60 80
[1] 10
[1] 25
[1] TRUE
```

=== "Python（NumPy）"

    ```python
    import numpy as np
    x = np.array([10, 20, 30, 40])
    print(x * 2)          # 各要素が2倍に
    print(x[0])           # 1番目の要素（0始まり！）
    print(x.mean())
    ```

    出力:

    ```text
    [20 40 60 80]
    10
    25.0
    ```

!!! danger "素の `list` は R の `c()` ではない"
    Python の組み込み `list` に `* 2` すると、**要素が2倍**ではなく**リストが2回繰り返さ**れます。R の感覚で `list` を使うと事故ります。数値計算は必ず NumPy / pandas に載せましょう。

    ```python
    print([10, 20, 30] * 2)
    # [10, 20, 30, 10, 20, 30]   ← 繰り返し。20,40,60 にはならない
    ```

## 2. 添字は 0 始まり（R は 1 始まり）

| | 最初の要素 | 最後の要素 |
|---|---|---|
| R | `x[1]` | `x[length(x)]` / `tail(x, 1)` |
| Python | `x[0]` | `x[-1]` |

`-1` で末尾から数えられるのは Python 側の便利な点です。範囲指定 `x[a:b]` は **`b` を含まない**（半開区間）ことも R と違うので注意。

## 3. 代入・真偽値・演算子

| 意味 | R | Python |
|---|---|---|
| 代入 | `x <- 1`（`=` も可） | `x = 1` |
| 真 / 偽 | `TRUE` / `FALSE`（`T`/`F`） | `True` / `False` |
| 等しい | `==` | `==` |
| かつ / または（スカラー） | `&&` / `\|\|` | `and` / `or` |
| かつ / または（ベクトル） | `&` / `\|` | `&` / `\|`（要素ごと） |
| 否定 | `!` | `not`（スカラー）/ `~`（配列） |
| べき乗 | `^` | `**` |
| 整数商 / 剰余 | `%/%` / `%%` | `//` / `%` |

!!! note "ベクトル条件の `&` `|` は Python でも同じ記号"
    pandas/NumPy で「複数条件のフィルタ」を書くときは `and`/`or` ではなく **`&`/`|`** を使い、各条件を**丸括弧で囲む**必要があります（→ [008. 行フィルタ](topic-008.md)）。

## 4. 欠損値：`NA` は Python では複数の顔を持つ

R の `NA` に相当するものは Python では文脈で変わります。詳細は [005. 欠損値の扱い](topic-005.md) で扱いますが、まずは対応だけ。

| R | Python | 主な出番 |
|---|---|---|
| `NA`（数値の欠損） | `np.nan`（float） | 数値列の欠損 |
| `NA`（一般） | `None` | 汎用の「値なし」 |
| `NULL`（存在しない） | `None` | 引数の未指定など |
| — | `pd.NA` | pandas の新しい統一欠損（文字・整数でも） |

**最大の違い**: R の集計関数は既定で NA を伝播（`mean(c(1,NA))` は `NA`）しますが、**pandas は既定で欠損を無視**（`skipna=True`）します。ここは事故りやすいので [005](topic-005.md) で詳述します。

## 5. 「データフレーム中心」は共通、道具が違う

R のデータ操作の主役は `data.frame` / `tibble` と dplyr です。Python では **pandas** か **polars** が主役になります。

| R | Python（pandas） | Python（polars） |
|---|---|---|
| `tibble` / `data.frame` | `DataFrame` | `DataFrame` |
| dplyr（`filter`/`mutate`…） | メソッド（`.query`/`.assign`…） | 式（`pl.col(...)`）|
| `%>%` / `\|>` | メソッドチェーン `.` | メソッドチェーン `.` |

発想としては、**polars の「式（expression）」が dplyr にいちばん近い**です。まず読めることを優先するなら pandas、新規の重い処理なら polars、と本ガイドは併記していきます。

## つまずきポイント

!!! warning "R 脳のまま Python を書くと踏む地雷"
    - **0 始まり**：`x[1]` は R では1番目、Python では**2番目**。
    - **`list` の掛け算**：`[1,2,3] * 2` は繰り返し。数値演算は NumPy/pandas へ。
    - **欠損の既定**：`mean` は R では NA 伝播、pandas では欠損無視。
    - **スライスの右端**：`x[0:2]` は index 0,1 の**2要素**（2 は含まない）。
    - **真偽の記号**：スカラーは `and`/`or`、配列条件は `&`/`|`（括弧必須）。
